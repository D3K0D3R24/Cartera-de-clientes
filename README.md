# Cartera de Clientes - Gestión de clientes y créditos

Aplicación de escritorio en **C# con Windows Forms** para la administración de clientes, pagos, créditos y respaldos de información. Desarrollada como proyecto escolar.

## Funcionalidades

- **CRUD completo** de clientes (Agregar, editar, eliminar, ver).
- Catalogación de clientes por categorías.
- Registro de pagos e historial de pagos por cliente.
- Gestión de créditos asignados a clientes.
- Respaldo de la información (backup).

## Tecnologías usadas

- C# .NET
- Windows Forms
- GunaFramework
- MySQL
